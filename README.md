📱 User Management App

Aplikasi Android sederhana untuk mengelola data pengguna (User Management) dengan fitur CRUD (Create, Read, Update, Delete).

📖 About The Project

User Management App merupakan aplikasi Android yang dibuat untuk mempermudah pengelolaan data pengguna. Aplikasi ini menyediakan antarmuka sederhana untuk menambahkan, melihat, memperbarui, dan menghapus informasi pengguna berupa nama dan email.

📖 Screenshot/ Tampilan
https://github.com/aldyrialdy/AppUserRoom/blob/master/Screenshot_20261112_114802.png

✨ Features
Add User – Menambahkan data pengguna baru berupa nama dan email.
Read User – Menampilkan daftar pengguna yang telah tersimpan.
Update User – Memperbarui informasi nama dan email pengguna.
Delete User – Menghapus data pengguna.
Simple UI – Tampilan aplikasi sederhana dan mudah digunakan.

📱 Application Preview

Aplikasi memiliki tiga tombol utama untuk mengelola data pengguna:

Button	Function
Add User	Menambahkan pengguna baru
Update User	Memperbarui data pengguna
Delete User	Menghapus data pengguna

Data pengguna ditampilkan dalam bentuk daftar yang berisi nama dan alamat email.

🎯 Project Purpose

Project ini dibuat sebagai sarana pembelajaran pengembangan aplikasi Android, khususnya dalam penerapan konsep CRUD (Create, Read, Update, Delete) dan pengelolaan data pengguna.
